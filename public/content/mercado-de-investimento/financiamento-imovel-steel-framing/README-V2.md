# Módulo FISF — pacote v2

Pacote de implementação do núcleo **Financiamento de Imóvel em Steel Framing**.

Inclui as quatro páginas do núcleo, imagens aprovadas e a pasta `integracao/` com:

- card para Home;
- card para Mercado de Investimento;
- CSS dos cards;
- rotas e SEO;
- fragmento de sitemap;
- checklist mobile/deploy.

A estrutura foi preparada para ser publicada sob:

`/mercado-de-investimento/financiamento-steel-framing/`

Antes da publicação definitiva, integrar os componentes ao framework/CMS real do steelframing.com.br e evitar duplicar metadados que já sejam gerados pelo layout global.
